## 2.1.0 - 2026-10-11

### Added

#### Added exclusive table sessions across OS processes with immediate and bounded acquisition waits.

`with_exclusive_table` is available for set, bag, and duplicate bag tables. Sessions acquire native ownership before DETS open or repair and close before release. Typed session errors preserve cleanup failures. All clients of a shared file must participate. Supported native targets require qualified local filesystems; escripts need a native companion directory.

### Fixed

#### Corrected website and API documentation for saving, repair, error handling, and table operations. Clarified examples and terminology.
#### Prevented false AlreadyOpen errors when concurrent table opens compete for an internal table name.
