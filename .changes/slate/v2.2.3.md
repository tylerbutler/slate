## 2.2.3 - 2026-11-17

### Fixed

#### Concurrent table writers wait their turn without random retry delays.

Queued writers get the next turn before a previous writer can acquire the same
lock again. Restart the BEAM VM when upgrading; do not hot-load this change
alongside callers that use the old locks. No API or data-file migration is
required.
#### Filename reporting returns valid UTF-8 paths and preserves file error categories in Unicode working directories.

This fixes reporting only. Input-path decoding and existing filenames are
unchanged: ordinary opens can still select the wrong file for a non-ASCII path.
Do not assume that reopening a reported non-ASCII filename selects the same
file.
#### Fixed `bag.insert_new` returning false `KeyAlreadyPresent` errors for distinct pairs that contain literal `_` or `$N` atoms, including nested terms.
#### Lookups return `DecodeErrors` for malformed DETS objects instead of raising or silently dropping entries.

Lookups and traversal require exact key-value pairs whose keys and values match
the configured decoders. `set.update_counter` returns `CounterValueNotInteger`
for malformed records without changing stored data. Rewrite records created
outside Slate as exact key-value pairs if they use other tuple sizes.
Slate-written pairs need no migration.
