## 2.2.1 - 2026-10-20

### Fixed

#### Fixed opening tables at the wrong location when an absolute path contains `..` segments that go above its root.

Unix roots, Windows drive roots, and UNC share roots remain intact.
#### Fixed `fold`, `fold_results`, and `to_list` so callers can handle corrupt-table failures as `DetsError` values.

Fixed `fold_results` stopping after one record when you use an `Error` or nested `Result` as the accumulator.
#### Fixed races between table opens and closes that could lose writes or damage files when several processes used the same table.

This protection applies to Slate operations within one Erlang VM. Use exclusive sessions when separate VMs can access the same file.

Restart the VM when upgrading with active tables. A failure of Slate's table-lifetime service stops new opens with `UnexpectedError`; restart the VM to recover.
#### Fixed `update_counter` changing a stored float before reporting an error.

Noninteger counter values remain unchanged when an update is rejected, including when other Slate callers write to the same table.
